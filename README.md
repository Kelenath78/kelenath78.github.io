# CYBERCITY OVERDRIVE — site officiel

Site public du jeu, servi par GitHub Pages sur **https://cybercity-overdrive.fr**.

- `index.html` : page d'accueil (présentation, classes, bestiaire, boss, installation)
- `jouer/` : le jeu (installable, jouable hors ligne)
- `img/` : illustrations
- `CNAME` : nom de domaine

Le code source et la compilation de l'APK sont dans le dépôt privé `Cybercity-Overdrive.github.io`.
